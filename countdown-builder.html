1Download the timer files

One zip with everything Cloudflare needs: the timer, your font, and a 24-second backup timer for when the free plan runs out of requests.

2Put it online with Cloudflare

The timer runs on Cloudflare Pages, a free hosting service. Every time someone opens an email, their email app asks Cloudflare for the image, and Cloudflare draws a fresh countdown. The free plan covers it.

Need an account?

If Melodics already has a Cloudflare account with the timer in it, ask for access and skip to Updating the timer. If not, sign up at cloudflare.com. Use a shared Melodics address like support@melodics.com, not a personal one. If the account belongs to one person, the timer stops working when their email is closed.

Setting it up the first time

  1. In the Cloudflare dashboard, go to Workers & Pages in the sidebar.
  2. Click Create application. Skip the Worker options, look for the line near the bottom about deploying Pages, and click Get started next to it. Choose Drag and drop your files.
  3. Name the project, e.g. melodics-countdown. The name becomes part of the web address. Click Create project.
  4. Drag in the zip from step 1 and click Deploy site.
  5. Copy the address it gives you, ending in pages.dev, for step 3.

Updating the timer

  1. Download a new zip from step 1.
  2. In Workers & Pages, open the timer’s project and go to Deployments.
  3. Click Create deployment, make sure it’s set to Production, drag in the zip, and deploy. The address stays the same, so emails using it pick up the change automatically.

Button names in Cloudflare may differ slightly. Leave the project’s Functions setting on fail open, which is the default. That’s what switches to the backup timer if the free plan’s daily requests run out.

{{{snippet "Countdown timer" "2026-12-01T00:00"}}}

Put the deadline in the copy near the timer too, so the email still makes sense if the image doesn’t load. A wrong or missing date shows a broken image, so mistakes get caught in proofs.
